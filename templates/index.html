CSV Format Guide

Required Columns:
  • studytime: 1-4 (1: <2h, 2: 2-5h, 3: 5-10h, 4: >10h)
  • failures: Number of past failures (0-4)
  • absences: Number of absences (0-93)
  • G1: First period grade (0-20)
  • G2: Second period grade (0-20)
Optional Columns:
  • famsup: Family support (yes/no)
  • schoolsup: Extra school support (yes/no)
  • internet: Internet access at home (yes/no)
  • paid: Extra paid classes (yes/no)
Note: The CSV file should not have an index column. Use the sample template to ensure correct format.
